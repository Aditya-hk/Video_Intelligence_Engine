Core Features

A complete pipeline for processing video content and retrieving relevant information.

🎬 Video Processing

Accept video input and extract its audio for downstream speech processing.

🎙️ Speech Recognition

Use Faster-Whisper to convert spoken audio into text transcripts.

🧠 Semantic Embeddings

Use Sentence Transformers to represent transcript chunks as numerical vectors.

🔎 Semantic Search

Store and retrieve relevant transcript segments through ChromaDB.

💬 AI Question Answering

Use retrieval-augmented generation to answer questions using retrieved context.

⏱️ Contextual Information

Use transcript timestamps where available to associate information with video segments.

How It Works

From raw video to context-aware answers.

  1. Upload a video through the application.
  2. Extract audio using FFmpeg.
  3. Transcribe speech using Faster-Whisper.
  4. Split the transcript into smaller chunks.
  5. Generate embeddings using Sentence Transformers.
  6. Store and retrieve vectors using ChromaDB.
  7. Generate answers through the RAG pipeline.
